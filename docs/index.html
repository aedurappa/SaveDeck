Pick up your game exactly where you left off — on any device. 어느 기기에서든, 하던 곳에서 바로 이어서.

SaveDeck syncs save files for games that have no Steam Cloud — between your PC, Steam Deck and more. 스팀 클라우드가 없는 게임의 세이브를 PC, 스팀덱 등 여러 기기 사이에서 동기화합니다.

How it works사용 방법

  • Add the same game name on every device and point it at that device's save path.
  • Press Sync — over your local network (P2P) or through your own Google Drive.
  • SaveDeck compares the saves, transfers only what changed, and backs up before overwriting.
  • 모든 기기에 같은 게임 이름으로 추가하고, 기기마다 그 기기의 세이브 경로를 지정합니다.
  • 동기화를 누르면 같은 네트워크(P2P) 또는 본인의 구글 드라이브로 맞춰 줍니다.
  • 세이브를 비교해 바뀐 파일만 전송하고, 덮어쓰기 전에 백업을 남깁니다.

Features주요 기능

  • LAN peer-to-peer — devices on the same network find each other automatically.
  • Optional Google Drive sync — plain folders and files in a SaveDeck folder in your own Drive.
  • Safe — SHA-256 verification, atomic replace, rolling .bak backups, conflict detection.
  • Steam Deck friendly — hidden folders are visible in the path picker.
  • 같은 네트워크 P2P — 같은 네트워크의 기기를 자동으로 찾습니다.
  • 선택 기능: 구글 드라이브 동기화 — 본인 드라이브의 SaveDeck 폴더에 일반 폴더와 파일 그대로 저장됩니다.
  • 안전 — SHA-256 검증, 원자적 교체, .bak 백업 순환, 충돌 감지.
  • 스팀덱 친화적 — 경로 선택 창에 숨김 폴더가 보입니다.

Google Drive permission구글 드라이브 권한

If you choose Google Drive sync, SaveDeck requests only the drive.file scope. It can access only the files and folders SaveDeck itself created — never your other Drive files. Nothing is sent to the developer.

구글 드라이브 동기화를 선택하면 drive.file 권한만 요청합니다. SaveDeck이 직접 만든 파일과 폴더에만 접근하며, 드라이브의 다른 파일은 볼 수 없습니다. 개발자에게 전송되는 정보는 없습니다.
