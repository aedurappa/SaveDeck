Pick up your game exactly where you left off — on any device. 어느 기기에서든, 하던 곳에서 바로 이어서.

SaveDeck syncs save files for games that have no Steam Cloud — between your PC, Steam Deck and more. 스팀 클라우드가 없는 게임의 세이브를 PC, 스팀덱 등 여러 기기 사이에서 동기화합니다.

How it works사용 방법

  • Add the same game name on every device and point it at that device's save path.
  • Press Sync — over your home network or through your own Google Drive.
  • SaveDeck sends only what changed, and keeps a backup of the old save before replacing it.
  • 모든 기기에 같은 게임 이름으로 추가하고, 기기마다 그 기기의 세이브 경로를 지정합니다.
  • 동기화를 누르면 같은 네트워크 또는 본인의 구글 드라이브로 맞춰 줍니다.
  • 바뀐 파일만 보내고, 세이브를 바꾸기 전에 이전 파일을 백업해 둡니다.

Features주요 기능

  • Works on your home network — your devices find each other automatically. No account needed.
  • Optional Google Drive — saves are stored as ordinary folders and files in your own Drive, so you can open, download or delete them there.
  • Your old save is never lost — a backup copy is kept before any save file is replaced.
  • Won't overwrite blindly — if it can't tell which save is newer, it leaves both alone and tells you.
  • Steam Deck friendly — the folder picker shows hidden folders.
  • 집 네트워크에서 바로 동기화 — 같은 네트워크의 내 기기를 자동으로 찾습니다. 계정이 필요 없습니다.
  • 선택 기능: 구글 드라이브 — 내 드라이브에 일반 폴더와 파일 그대로 저장돼서, 직접 열어 보고 내려받고 지울 수 있습니다.
  • 기존 세이브가 사라지지 않습니다 — 세이브 파일을 바꾸기 전에 이전 파일을 백업해 둡니다.
  • 함부로 덮어쓰지 않습니다 — 어느 쪽이 최신인지 알 수 없으면 아무것도 건드리지 않고 알려 줍니다.
  • 스팀덱에서도 편하게 — 폴더 선택 창에 숨김 폴더가 보입니다.

Google Drive permission구글 드라이브 권한

If you choose Google Drive sync, SaveDeck asks for only the smallest Google Drive permission (drive.file). It can access only the files and folders SaveDeck itself created — never your other Drive files. Nothing is sent to the developer.

구글 드라이브 동기화를 선택하면 가장 작은 구글 드라이브 권한(drive.file)만 요청합니다. SaveDeck이 직접 만든 파일과 폴더에만 접근하며, 드라이브의 다른 파일은 볼 수 없습니다. 개발자에게 전송되는 정보는 없습니다.
